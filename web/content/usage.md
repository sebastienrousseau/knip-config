# Usage

`@sebastienrousseau/knip-config` can be consumed across all standard module formats.

## CommonJS

```javascript
module.exports = require("@sebastienrousseau/knip-config");
```

## ES Modules

```javascript
import config from "@sebastienrousseau/knip-config";
export default config;
```

## In `package.json`

```json
{
  "knip": "@sebastienrousseau/knip-config"
}
```
